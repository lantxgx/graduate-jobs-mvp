## 本轮验证结果（2026-08-19）

- 蔚来：入口可达；首条详情页正文缺少可直接解析的城市和招聘类型，质量门禁拒绝入库，配置暂设 `enabled=false`。
- 360：入口可达；北森通用解析器没有产出合格具体岗位，配置暂设 `enabled=false`。
- 阿里巴巴：入口可达；通用 JSON 发现器没有产出合格具体岗位，配置暂设 `enabled=false`。
- 百度：入口可达；通用 JSON 发现器没有产出合格具体岗位，配置暂设 `enabled=false`。

这些不是“没有岗位”的结论，而是“当前适配器没有完成字段级接入”的结论。下一步应为每个来源做一次公开页面结构分析，再决定专用适配器或人工辅助导入。

## 领取规则

一次只领取一家公司。先用浏览器打开入口并做只读核验；如果地址失效或跳转到第三方平台，记录最终可见地址和官方归属证据，不要凭记忆替换成其他地址。核验通过后再提交 `config/sources.json` 的最小变更和对应适配器。

## 接入优先级

1. 页面已有公开 JSON 且网络请求稳定：实现专用适配器，但只复用页面正常加载时可见的公开响应。
2. 页面是飞书、北森、Moka、Greenhouse、Lever 等标准 ATS：优先复用现有适配器或增加通用适配器配置。
3. 只有可见 HTML 卡片：使用 `custom_html`，必须从显式岗位卡片链接读取。
4. 需要登录、验证码、绕过安全验证或接口签名破解：标记为 `blocked`，不接入。
